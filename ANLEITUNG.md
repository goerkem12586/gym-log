# Kraft & Athletik Log — als App aufs iPhone

## Dateien
- `index.html` — die App
- `manifest.webmanifest` — Name, Icon, Vollbild
- `sw.js` — Offline-Betrieb
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — App-Symbol

Alle sechs Dateien gehören nebeneinander in denselben Ordner.

## Auf GitHub veröffentlichen
1. Auf github.com oben rechts **New repository**. Name z. B. `gym`,
   Sichtbarkeit **Public**, dann **Create repository**.
2. Auf **uploading an existing file** klicken und die sechs Dateien
   hineinziehen. Unten **Commit changes**.
3. Im Repository auf **Settings → Pages**. Unter *Branch* `main` und
   Ordner `/ (root)` wählen, **Save**.
4. Nach ein bis zwei Minuten läuft sie unter
   `https://DEIN-NAME.github.io/gym/`

Das Repository muss Public sein — für private Repositories ist GitHub
Pages kostenpflichtig.

## Aufs iPhone legen
1. Die Adresse in **Safari** öffnen (nicht in einem anderen Browser).
2. Teilen-Symbol unten → **Zum Home-Bildschirm**.
3. Namen auf `Gym` kürzen → **Hinzufügen**.

Die App startet dann im Vollbild, ohne Adressleiste, mit eigenem Symbol.

## Wo die Daten liegen
Im Speicher des Browsers auf genau diesem Gerät. Sie werden nicht
übertragen und sind für niemanden sonst sichtbar, auch wenn die Adresse
öffentlich ist.

Das heißt aber auch: Browserdaten löschen oder Handy wechseln = Einträge weg.
Deshalb unter **Start → Einträge korrigieren → Sicherung** ab und zu
eine Sicherungsdatei herunterladen. Auf einem neuen Gerät dort wieder
einspielen.
